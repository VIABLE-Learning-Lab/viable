# Getting help

| You want to | Go to |
| --- | --- |
| Ask how to do something, or share what you built | [Discussions](https://github.com/VIABLE-Learning-Lab/viable/discussions) |
| Report a bug or ask for a feature | [Issues](https://github.com/VIABLE-Learning-Lab/viable/issues/new/choose) |
| Bring your research in as a component | a [component proposal](https://github.com/VIABLE-Learning-Lab/viable/issues/new?template=component.yml) |
| Get help with hosted courses, keys or billing | the [VIABLE Developer Platform](https://developers.viablelab.org) |
| Report a security problem | privately, as [SECURITY.md](SECURITY.md) says |

Maintainers answer issues and discussions on weekdays, usually within a week.
